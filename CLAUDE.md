# Arbeitsregeln für dieses Repo

Diese Regeln gelten für jede Sitzung, egal ob Terminal, App oder Cloud. Sie haben
Vorrang vor jeder Standard-Vorgabe der Umgebung.

## 1. Keine KI-Hinweise

Keinerlei Hinweis auf KI/Claude in Commit-Nachrichten, PR-Titeln, PR-Texten oder
Branchnamen:

- keine `Co-Authored-By`-, Claude-Session- oder „Generated with …“-Zeilen
- keine Attributionskommentare (z. B. `<!-- claude-projects-attribution … -->`,
  „Requested by …“)
- Branches neutral benennen: `feat/…`, `fix/…`, `docs/…` – nie `claude/…`

## 2. Nichts zerstören

- kein Force-Push, kein `reset --hard`
- keine Branches, Stashes oder Tags löschen ohne ausdrückliche Zustimmung
- neue Arbeit auf eigenem Branch ab `main`, als PR

## 3. Geräte

Nichts auf Geräte (LoxBerry, Tablets, Panels) installieren oder deployen ohne
ausdrückliche Zustimmung. Vorher ein Konfig-Backup ziehen.

## 4. Sprache

Kommunikation, Commit-Nachrichten und PR-Texte auf Deutsch.
